# Akash Biswas — Data Science & Research

One-page portfolio published at https://deeplearning186.github.io/.

## Featured work

- Employee Retention Analysis and Prediction: 1,470 employee records; logistic regression, random forest and neural network models.
- Sales Department: 1,017,209 daily sales records, store metadata and an exploratory 60-day Prophet forecast for Store 10.
- Stable Coin Distribution and Ownership Analysis: IJSREM, January 2023, DOI 10.55041/IJSREM17448.

Project links point to the original notebooks in [Personal-Projects](https://github.com/Deeplearning186/Personal-Projects). Scope and methods were checked against their saved contents. No unverified model-accuracy or business-impact claims are displayed. The sales-card graphic and hero point field are illustrative; the research preview is rendered from the actual paper.

## Editing and publishing

The site uses static HTML, CSS and JavaScript, with no build step or package dependencies. GitHub Pages serves the root of `main`; `.nojekyll` enables direct static publishing.

- `index.html`: content, project links and metadata.
- `style.css`: responsive layout, colors and typography.
- `script.js`: short decorative animation, reduced-motion support and current year.
- `assets/`: favicon, research cover and original research PDF.

Fonts are loaded from Google Fonts with local system fallbacks. The site contains no analytics, tracking or contact-form backend. Email links open the visitor’s mail application.
